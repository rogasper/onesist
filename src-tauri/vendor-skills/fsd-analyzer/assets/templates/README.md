# Output templates

Place **project-specific** boilerplate here (e.g. company API error envelope, standard audit columns).

The default structural templates live in **`references/`** (`spec_api_format.md`, `erd_format.md`, `task_format.md`).

Suggested optional files:

- `api_error_envelope.json` — sample error JSON
- `audit_columns.md` — snippet reused in every ERD table
